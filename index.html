🔍 What is WinDirectoryStats?

WinDirectoryStats is a powerful yet simple disk usage analyzer that instantly shows you what's eating up your storage space. Imagine being able to see your entire hard drive as a beautiful, color-coded map where each color represents a different file type. That's exactly what you get.

Whether you're a student with a full laptop, a professional with multiple drives, or just someone tired of "low disk space" warnings, WinDirectoryStats helps you find and remove large files quickly, without any technical hassle. It's built for speed and simplicity—designed natively for Windows 11 and Windows 10.

✨ Amazing Features

🗺️ Interactive Color-Coded Treemap

See your entire disk as a visual map. Each rectangle represents a folder or file, and its size shows how much space it takes. Colors represent different file types (videos, documents, images, etc.). Click any block to zoom in and explore!

📁 Complete Folder Tree View

Prefer a traditional list? The expandable folder tree shows you every directory and file, sorted by size. Great for beginners who want a clear, familiar view.

🏆 Largest Files Finder

Jump straight to the biggest files on your PC. Stop guessing—instantly know which videos, downloads, or backups are consuming your gigabytes. Sort, copy, or delete with just a few clicks.

Don't want to scan everything? Set a folder depth limit to scan only the top levels. This makes the analysis lightning-fast, even for massive drives.

💡 How to Use It (Beginner's Guide)

1. Scanning a Drive

The app opens and asks which drive you want to scan. Select your C: drive (or any other) and click "Scan." Watch the magic happen!

2. Reading the Treemap

After scanning, you'll see large colored rectangles. Bigger square = bigger file/folder. Blue is for videos, orange for images, red for documents, and so on. Hover your mouse over any block to see the full path and size.

3. Finding Large Files Quickly

Click "Largest Files" tab to see a sorted list from biggest to smallest. Look at the first few to find quick wins. Delete any files you don't need via your regular File Explorer.

4. Filtering by Depth

If scanning takes too long (e.g., large external drives), set the "Maximum depth" to 2 or 3. This scans only the top-level folders, giving you a fast overview.
